# 芒果疏果机器人底盘与执行机构固件 (`chassis/`)

基于 **Arduino Mega 2560 + Pro Max 扩展板 (`25.11.19 - V3.3`)** 的 PlatformIO 工程，适用于 B 类“芒果疏果机器人竞技”（专本组：7 条 `400 mm` 垄沟、6 条 `120 mm` 高田垄、含随机 2 条 `5.5 mm` 毛毯）。

当前固件已打通：**四路闭环底盘驱动 + 四路正交编码器 + 四路超声波居中循迹 + 维特 `HWT101CT-TTL` 单轴高精度陀螺仪 + 四路击打舵机（含方向与 90° 外扩标定）+ 双路 OpenMV `MV1` 串口接收**。

---

## 1. 实车尺寸与关键标定参数

- **实测整车外包络**：车长约 `320 mm`，含轮最外宽约 **`340 mm`**（居中于 `400 mm` 垄沟时左右轮缘各留约 `30 mm` 净空）；
- **超声波内缩**：实测内缩约 `41 mm`，`400 mm` 通道居中时单侧实测读数 **`L = 71 mm`** → 代码单侧控距目标已标定为 **`70 mm`**；
- **端头过弯策略**：车体对角线 `~467 mm > 400 mm`，不可原地自旋；代码采用 **提前稳停（前超声 `145 mm` ≈ 物理净空 `105 mm`）+ 偏置弧线 `90°` 过弯（`arc = 0.38`）+ 陀螺仪 PD 角速度阻尼 & 电磁刹车**。

## 2. 完整硬件接线表（扩展板 `12路舵机` 朝上、`12V/5V/GND` 在右下角）

### 2.1 四路直流电机（JGB37-520 12V/110RPM + 两块 L298N，4 个 `ENA/ENB` 跳帽全部拔掉）
| 轮位 | 扩展板丝印 | `EN` | `IN1` | `IN2` | 方向反转 | 前馈比例 |
|---|---|---:|---:|---:|---:|---:|
| 左前 (`FL`) | 左上 `直流 E5 24 25 GND` | `D5` | `D24` | `D25` | `false` | `0.96` |
| 左后 (`RL`) | 左中 `直流 E6 22 23 GND` | `D6` | `D22` | `D23` | `false` | `0.86` |
| 右前 (`FR`) | 右上 `直流 E7 26 27 GND` | `D7` | `D26` | `D27` | `true` | `0.85` |
| 右后 (`RR`) | 右中 `直流 E8 28 29 GND` | `D8` | `D28` | `D29` | `true` | `1.00` |

| 轮位 | 扩展板丝印 | 4 针顺序（务必核对方焊盘 `+5V`，反插会无脉冲！） | 计数反转 |
|---|---|---|---|
| 左前 (`FL`) | `编码 A12 A13 Gnd` | 左→右：`+5V(方焊盘)` → `A12` → `A13` → `Gnd` | `true` |
| 左后 (`RL`) | `编码 A8 A9 Gnd` | 上→下：`+5V(方焊盘)` → `A8` → `A9` → `Gnd` | `true` |
| 右前 (`FR`) | `编码 A14 A15 Gnd` | 左→右：`+5V(方焊盘)` → `A14` → `A15` → `Gnd` | `false` |
| 右后 (`RR`) | `编码 A10 A11 Gnd` | **下→上**：`+5V(方焊盘)` → `A10` → `A11` → `Gnd` | `false` |

### 2.3 四路超声波（HC-SR04，板载上方 `超声` 座，从左到右 `+5V | Trig | Echo | GND`）
| 方位 | 扩展板丝印 | `Trig` | `Echo` |
|---|---|---|---|
| 前 (`F`) | `超声 A4 A5 Gnd` | `A4` | `A5` |
| 右 (`R`) | `超声 A6 A7 Gnd` | `A6` | `A7` |
| 后 (`B`) | `超声 A2 A3 Gnd` | `A2` | `A3` |
| 左 (`L`) | `超声 A0 A1 Gnd` | `A0` | `A1` |

### 2.4 三路硬件串口分配（左下角 `四组UART串口` + `陀螺仪` 座，零冲突）
> **注意**：左下角横排 `陀螺仪 R19 T18` 与下方竖排串口 `1 (T18 R19)` 在 PCB 内部并联，均属于 `Serial1`，**只供陀螺仪独占**，切勿再插 OpenMV！

| 硬件串口 | 扩展板座子 | 外设 | 波特率 / 协议 | 接线与供电注意点 |
|---|---|---|---|---|
| `Serial` | `0 (T1 R0)` / USB | 电脑调试 | `115200` | 烧录与串口指令口，勿占用 |
| `Serial1` | `陀螺仪 (R19 T18)` | **维特 `HWT101CT-TTL`** | `9600` / `0x55 0x52,0x53` (`20 Hz`) | `TX→R19`, `RX→T18`, `GND` 共地；**供电需 `9~36V`（接 12V 电池，勿接 5V）** |
| `Serial2` | `2 (T16 R17)` | **OpenMV #1** | `115200` / `$MV1,...*XX` | `P4(TX)→R17`, `P5(RX)→T16`, `GND` 共地；OpenMV 端 `config.py` 须设 `UART_ENABLED=True` |
| `Serial3` | `3 (T14 R15)` | **OpenMV #2** | `115200` / `$MV1,...*XX` | `P4(TX)→R15`, `P5(RX)→T14`, `GND` 共地；同上 |

### 2.5 四路击打舵机（顶部 `12路舵机` 排针，占用 Mega `Timer5`，不冲突 `D5~D8` 电机 PWM）
- **排针方向**（数字丝印朝上）：最上排 `信号 (黄/橙)` | 中间排 `+6V (红)` | 最下排 `GND (棕/黑)`；
- **独立供电**：由扩展板右上角 **`6V`** 接口输入，使用 `HW-920` 大电流稳压模块（**务必将内侧 `CC` 限流电位器顺时针放开，避免带载掉压至 5V 以下**，推荐输出 `5.8V ~ 6.5V`）。

| 通道名 | 引脚 | 位置 | 竖直收回角 (`HOME`) | 外扩 90° 击打角 (`OUT/HIT`) | 外扩方向 |
|---|---:|---|---:|---:|---|
| `LD` | `D32` | 左低 | `30°` | `120°` | 角度增大 (`+90°`) |
| `RD` | `D33` | 右低 | `150°` | `60°` | 角度减小 (`-90°`) |
| `LU` | `D34` | 左高 | `150°` | `60°` | 角度减小 (`-90°`) |
| `RU` | `D35` | 右高 | `30°` | `120°` | 角度增大 (`+90°`) |

### 2.6 外接启动/急停按键（可选）
- 接扩展板中左侧 `5V 2` 座子的 `D2` 与 `GND`（内部上拉，不接不影响）。停机按一下倒计时 `1.5 s` 发车，运行中按一下立即急停。

## 4. 上电自启模式（`include/config.h` 中修改 `AUTO_START_MODE`）

| `AUTO_START_MODE` | 行为说明 | 适用场景 |
|---:|---|---|
| `0` | **安全待机**：电机和舵机均不动作，仅响应串口或 `D2` 按键 | 插 USB 读传感器、测 OpenMV、标定舵机 |
| `1` | 上电倒计时 `3 s` → **L 形测试**（直行 `800 mm` → 原地右转 `90°` → 直行 `800 mm`） | 空地验证直线锁直与 90° 转向精度 |
| `2` | 上电倒计时 `3 s`（先自动收拢 4 根击打杆）→ **完整 7 垄比赛闭环** | 脱机上场地跑完全程 |
| `3` | 上电 `1.5 s` 后底盘停机、单路舵机持续 `20°↔160°` 循环摆动 | 拔 USB 脱机用万用表调 `HW-920` 6V 供电 |
| `4` | 上电倒计时 `3 s`（先自动收拢 4 根击打杆）→ **单垄居中循迹至端头停稳** | 进真垄沟单独验收居中、过毛毯与停距 |

> **安全提醒**：烧录 `AUTO_START_MODE != 0` 前，务必先关闭 12V 动力总电源或架空车轮！

## 5. 完整比赛闭环路线（`AUTO_START_MODE = 2` 或串口发 `F`）

1. **自动收杆 & 归零**：锁定 `LD/RD/LU/RU` 至竖直贴身位，`HWT101CT` 当前朝向软件归零为 `0.0°`；
2. **出库直冲顶围栏（`EXIT`）**：软起步沿左外围栏做左侧超声 PD 定距（`70 mm`）+ 陀螺仪 `0°` 锁直，直达顶围栏（前超声 `≤ 145 mm` 连续 2 帧确认）停稳；
3. **弧线进入 7 号沟（`TURN_EN`）**：前向偏置弧线右转 `90°`（`arc = 0.38`，PD 阻尼 + 电磁刹车）进入第 7 沟（`+X`）；
4. **7 垄蛇形遍历（`LANE` + `TURN1/CROSS/TURN2`）**：由 7 号沟自上而下遍历至 1 号沟；每次端头 U 形换垄结合外侧贴墙 `70 mm`、内侧超声扫垄端面边沿、过垄后编码器 `140 mm` 对中及 `680 mm` 总里程兜底（兼容短垄 `R4`）；
5. **倒车对口 & 回启动区（`RET_REV` → `TURN_HM` → `PARK`）**：1 号沟末端沿沟倒车居中退回，后超声 `≤ 135 mm` 停稳于左围栏前 → 后退偏置弧线右转 `90°` 面向入口 → 编码器闭环直行 `650 mm` 完整停入启动区。

## 6. 串口调试指令速查（`115200 bps`）

| 指令 | 说明 |
|---|---|
| `空格` 或 `X` | 立即急停并中止所有任务与测试 |
| `P` / `U` | 打印全部引脚、传感器与参数汇总 / 开、关实时遥测（`F/B/L/R`、Yaw、PWM） |
| `G` / `B` | 单垄前进 / 倒车居中循迹 |
| `D <mm>` | 编码器定距直行（带陀螺仪锁直与超声防撞，如 `D 500`） |
| `LT [d1] [L\|R] [d2] [A]` | 直线 → 90° 转弯 → 直线地面测试（末尾加 `A` 改弧线转） |
| `TL` / `TR` / `AL` / `AR` | 单测原地左/右 90° 与前向弧线左/右 90° |
| `UL` / `UR` | 单测一次完整左/右 U 形换垄 |
| `F [lanes]` / `M [lanes] [L\|R]` | 跑完整比赛闭环（默认 7 垄）/ 仅跑多垄蛇形 |
| `Z` / `CAL` / `RATE <5\|10\|20>` / `I` | 陀螺仪软件归零 / HWT101CT 硬件 Z 归零 (`0x76`) / 改频并保存 / 抓原始 HEX |
| `SV HOME` / `SV OUT <ch>` / `SV HIT <ch>` / `SV OFF` | 四杆贴身收回 / 单路外扩 `90°` / 模拟外扩击打并自动收回 / 断力释放（`<ch>` 支持 `ld/rd/lu/ru/32..35`） |
| `MV` / `MVRAW` / `MVLOG` | 查双路 OpenMV (`Serial2/3`) 状态 / 原始串口抓包 / 开、关逐帧实时打印 |
| `W <fl\|rl\|fr\|rr\|l\|r\|all> <pwm> [ms]` | 单轮或整车架空电机测试 |
| `E` / `EC` / `SCALE <w> <val>` | 查看四轮编码器里程与轮速 / 清零计数 / 微调单轮前馈比例 |
| `SET <key> <val>` / `SAVE` / `LOAD` / `RESETCFG` | 在线调参（`kp/kd/ykp/spd/stop/rstop/arc/cout/cmm/cmax/hdist/vpid` 等）/ EEPROM 保存、重载、复位 |

## 7. 开发工具、编译烧录与实车验证记录

### 7.1 工具与依赖版本
- **工具链**：VS Code + PlatformIO (`platform = atmelavr@5.3.0`, `framework-arduino-avr@5.4.0`, `toolchain-atmelavr@7.3.0`)
- **库依赖**（见 `platformio.ini`）：`arduino-libraries/Servo@1.3.0`、`EEPROM@2.0`
- **构建与烧录命令**（在 `chassis/` 目录下执行）：

```powershell
# 仅编译
pio run

# 烧录至 Mega 2560（将 COM9 替换为实际端口）
pio run --target upload --upload-port COM9

# 打开串口监视器
pio device monitor --port COM9 --baud 115200
```
