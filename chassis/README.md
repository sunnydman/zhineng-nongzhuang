# 四轮差速 + 四超声 + 六轴 IMU 芒果疏果底盘固件

基于 **Arduino Mega 2560 + Pro Max 扩展板 (`25.11.19 - V3.3`)** 的 PlatformIO 工程，适用于 B 类“芒果疏果机器人竞技”场地（7 条 `400 mm` 垄沟、6 条 `120 mm` 高田垄、含随机两条毛毯）。

## 1. 接线一览（扩展板 `12路舵机` 朝上、`12V/5V/GND` 在右下角）

### 四路直流电机（两块 L298N，4 个 `ENA/ENB` 跳帽全部拔掉，按新车头方向映射）
| 轮位 | 扩展板丝印 | `EN` | `IN1` | `IN2` | 注意事项 |
|---|---|---:|---:|---:|---|
| 左前 (FL) | 左上 `直流 E5 24 25 GND` | `D5` | `D24` | `D25` | 左侧丝印从上到下：`EN→IN1→IN2→GND` |
| 左后 (RL) | 左中 `直流 E6 22 23 GND` | `D6` | `D22` | `D23` | 同上 |
| 右前 (FR) | 右上 `直流 E7 26 27 GND` | `D7` | `D26` | `D27` | 右侧丝印从下到上：`EN→IN1→IN2→GND` |
| 右后 (RR) | 右中 `直流 E8 28 29 GND` | `D8` | `D28` | `D29` | 同上 |

### 四路超声波（HC-SR04，板载上方 `超声` 座，从左到右 `+5V | Trig | Echo | GND`）
| 方位 | 扩展板丝印 | `Trig` | `Echo` |
|---|---|---|---|
| 前 (F) | `超声 A4 A5 Gnd` | `A4` | `A5` |
| 后 (B) | `超声 A2 A3 Gnd` | `A2` | `A3` |
| 左 (L) | `超声 A0 A1 Gnd` | `A0` | `A1` |
| 右 (R) | `超声 A6 A7 Gnd` | `A6` | `A7` |

### 单轴高精度陀螺仪（维特 `HWT101CT-TTL` → `Serial1`，协议 `0x55 0x52/0x53`，默认 `9600 bps`）
- `R19` (`RX1`) → **HWT101CT `TX`**
- `T18` (`TX1`) → **HWT101CT `RX`**
- `GND` → **HWT101CT `GND`（必须与 Mega 和 12V 电池共地）**
- `9~36V 电源正` → **接车上 `12V` 电池正极**（切勿接 5V）

### 四路正交编码器（红圈 `编码` 4P 座 → `A8–A15` / `PCINT2`，AB 四倍频，按新车头方向映射）
| 轮位 | 扩展板丝印 | 4 针顺序（务必核对方焊盘 `+5V`！） |
|---|---|---|
| 左前 (FL) | `编码 A12 A13 Gnd` | 左→右：`+5V(方焊盘)` → `A12` → `A13` → `Gnd` |
| 左后 (RL) | `编码 A8 A9 Gnd` | 上→下：`+5V(方焊盘)` → `A8` → `A9` → `Gnd` |
| 右前 (FR) | `编码 A14 A15 Gnd` | 左→右：`+5V(方焊盘)` → `A14` → `A15` → `Gnd` |
| 右后 (RR) | `编码 A10 A11 Gnd` | **下→上**：`+5V(方焊盘)` → `A10` → `A11` → `Gnd` |

### 外接启动/急停按键（可选）
- 接扩展板中左侧 `5V 2` 座子的 `D2` 与 `GND`（内部上拉，不接不影响）。停机按一下倒计时 `1.5 s` 发车，运行中按一下急停。

> **供电安全**：电池负极、两块 L298N `GND`、扩展板 `GND` 必须共地；两块 L298N 的 `5V` 端子悬空不接；USB 调试期间先断开 12V 动力电测通传感器，再架空四轮测试电机。

## 2. 跑完全程闭环路线（串口发 `F` 或 `F 7`）

1. **出启动区直达 7 号沟（`EXIT`）**：车在启动区车头朝内（`+Y`），清零 IMU 航向 `0°`，沿左侧外围栏直行至顶围栏（`Y=4600`）停稳；
2. **进入 7 号沟（`TURN_EN`）**：右转 `90°`（`-90°`）面向 `+X`；
3. **7 垄蛇形遍历（`LANE` + `TURN1/CROSS/TURN2`）**：由 7 号沟自上而下蛇形走完 7 条垄沟（右 U 弯→6 号沟→左 U 弯→5 号沟→…→1 号沟），跨垄时通过内侧超声识别 `扫到垄端面 → 离开垄端面` 定位新沟口（兼容短垄 `R4` 的 `600 mm` 端头通道）；
4. **倒车回入口（`RET_REV`）**：跑完 1 号沟（停在右围栏）后，沿 1 号沟倒车居中退回，靠**后置超声**停在左围栏前（正好对准 `400 mm` 出入口中心）；
5. **转正回启动区（`TURN_HM` → `PARK`）**：右转 `90°`（`180°`）面向入口外，直行驶入启动区并停稳。

## 3. 串口命令速查（`115200` 波特率）

| 命令 | 说明 |
|---|---|
| `空格` 或 `X` | 立即急停并中止任务 |
| `U` | 开/关实时遥测（`F/B/L/R` 距离、IMU 偏航角、当前状态、左右 PWM） |
| `I` / `VER` / `CAL` / `Z` | 抓 `Serial1` 原始 HEX 包 / 查 IMU 版本 / 陀螺仪静止校准 / 偏航角软件归零 |
| `RATE <5\|10\|20>` / `BAUD <rate>` | 设置 HWT101CT 回传速率并掉电保存（`9600 bps` 下已设为 `20 Hz`）/ 在线切换 `Serial1` 波特率 |
| `W <fl\|rl\|fr\|rr\|l\|r\|all> <pwm> [ms]` | 架空单轮或整车测试（默认 `1500 ms` 自动停） |
| `SV [32\|33\|34\|all] <deg\|test\|off>` | 测试/控制顶部 `12路舵机`（如 `SV 33`、`SV 33 90`、`SV OFF` 断力释放） |
| `SCALE <fl\|rl\|fr\|rr> <0.50..1.30>` | 在线微调单个轮子的 PWM 比例系数（配 `SAVE` 掉电保存） |
| `E` / `EC` | 查看四轮编码器脉冲、里程（mm）与轮速（mm/s）/ 编码器计数值清零 |
| `G` / `B` | 单垄前进 / 倒车居中循迹（400mm 沟居中超声目标 `85 mm`，前停 `140 mm`） |
| `D <mm>` | 编码器定距直行（带 IMU 航向锁直与超声防撞，如 `D 500` / `D -300`） |
| `LT [d1] [L\|R] [d2] [A]` | **直线→90°转弯→直线**地面测试（默认 `LT` = 直行 `800mm`→原地右转 `90°`→直行 `800mm`；末尾加 `A` 改弧线转） |
| `TL` / `TR` | 单测原地左/右转 `90°`（`AL` / `AR` 为适配 `320×310mm` 车体的前向偏置弧线 `90°` 过弯） |
| `UL` / `UR` | 单测一次完整左/右 U 形换垄（弧线 90° → 超声波边沿 + 编码器 `140 mm` 对中 / `680 mm` 兜底 → 弧线 90°） |
| `M [lanes] [L\|R]` | 仅跑多垄蛇形（默认 `M 7 L`） |
| `F [lanes]` | **跑完整场比赛闭环**（默认 `F 7`：出库→7 垄→倒车对口→编码器 `650 mm` 回启动区停稳） |
| `P` / `SET <key> <val>` | 打印当前配置 / 在线调参（含 `arc` 弧线偏置比、`cmm` 过垄对中里程、`cmax` 跨垄兜底里程、`hdist` 回库里程、`vpid` 速度闭环等） |
| `SAVE` / `LOAD` / `RESETCFG` | 将 `SCALE` 和 `SET` 调好的参数保存到 EEPROM（掉电不丢）/ 重载 / 恢复默认 |

## 4. 实车落地调试顺序（建议按步验证，随时按 `空格` 急停）

1. **直线里程与锁直**：空地放车，发送 `D 500`，用尺子核对实际是否直走 `500 mm` 且不明显跑偏。
2. **弧线 90° 过弯**：把车摆在通道端头前（距前围栏约 `100 mm`），发送 `AR`（右转）和 `AL`（左转），观察车角不擦碰围栏且转正 `90°`；若外角偏近调小 `arc`（如 `SET arc 0.30`），若内角偏近调大 `arc`（如 `SET arc 0.40`），若原地转不动调大 `tmin`（如 `SET tmin 125`）。
3. **单垄居中循迹**：放进任意一条 `400 mm` 垄沟，发 `G` 跑通整条沟并核对端头停稳距离（`stop` 默认 `140 mm` = 车头距围栏 `100 mm`）；再发 `B` 验证倒车居中。
4. **单次 U 形换垄**：在沟端头停稳后发 `UR` 或 `UL`，确认跨过 1 条田垄后正好对准下一条沟口；过深调小 `cmm`，偏浅调大 `cmm`。
5. **分段联调与跑完全程**：放回启动区车头朝内，先发 `F 2` 验证“出库 → 7号沟 → 换6号沟 → 倒车回入口 → 回库停稳”，确认无误后发 `F 7` 跑完全程！调优完成后发 `SAVE` 掉电保存。

## 5. 开发工具、依赖版本与编译烧录

- **开发工具**：VS Code + PlatformIO IDE（或 PlatformIO Core CLI）
- **目标平台与框架**：`platform = atmelavr`（5.3.0）、`board = megaatmega2560`、`framework = arduino`（5.4.0）
- **依赖库**（见 `platformio.ini`）：
  - `arduino-libraries/Servo@^1.2.2`（实测编译 `1.3.0`，占用 Mega 2560 `Timer5`）
  - 内置 `EEPROM@2.0`
- **编译与烧录命令**（在 `chassis/` 目录下执行）：

```powershell
# 仅编译检查
pio run

# 烧录到 Mega 2560（将 COM9 替换为实际串口号）
pio run --target upload --upload-port COM9

# 打开串口监视器（115200 bps）
pio device monitor --port COM9 --baud 115200
```

> **安全提醒**：`include/config.h` 中的 `AUTO_START_MODE` 控制上电自动行为（`0`=待机，`1`=上电 3 秒后自动跑 L 形测试，`2`=上电 3 秒后跑全程 7 垄，`3`=脱机循环测舵机）。烧录非 `0` 模式前请先确认 12V 动力电已关或车轮架空。
