# OpenMV 芒果识别

| 目录 | 用途 |
|---|---|
| [停车版](停车版/) | 单边停车作业相机端。倒装翻转、绿色果高低位识别、中央竖线对准和补光标定。 |
| [当前版本](当前版本/) | v011 独立视觉调试版，保留 MV1 接口。运行时将 [击打判断](击打判断/) 中的 strike_decision.py 与同版本模块放在相机盘根目录。 |

## 停车版部署

- 标定时，把停车版的 config.py、vision.py、strike_decision.py、harvest_vision.py 和 harvest_camera.py 放在 OpenMV 盘根目录，用 IDE 临时运行 lab_probe.py。脚本打印 LAB 分位数、果框尺寸和判断状态，全程无需 Mega。
- 车上联调时，成套保存停车版的七个作业脚本。将 lab_probe.py 留作 IDE 调试。相机默认上下、左右翻转，使用 QVGA 的 x=160 竖线对准。
- 停车版默认发送 HV2，需配套支持 HV2 的 Mega 固件。本提交只包含相机侧。当前主分支上的底盘请继续使用兼容的 MV1 视觉调试版。
- 补光下的 LAB 区间、高低果的近距尺寸门槛需用现场数据标定。未填写某高度的近果尺寸门槛时，该高度不会给出对准许可。
