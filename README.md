# 单边停车疏果初版

底盘基于 GitHub `ec1e892`，视觉基于本地 v011。OpenMV 装在作业侧，一个舵机用两个实测角度处理高低绿果。车见树减速，在果心接近画面中央竖线时停车，用停稳后的新画面复核，再出杆和回收。当前供单树短测、单边单沟测试及可选的比赛单工位接入。

[测试说明](测试说明.md)包含舵机台架、PlatformIO 烧录、补光 LAB 标定和实车调参。默认舵机角度、近果尺寸和整沟工位是待标定值。比赛全程的单工位接入由 `HARVEST_MISSION_LANE` 与 `HARVEST_STATION` 控制，初始关闭。

[双边移动测试](双边单沟测试.md)保留作旧机构参考。
